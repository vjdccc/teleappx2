# Telethon Zahid — مشروع تطبيق اندرويد

## البناء (مرة واحدة على الكمبيوتر)
1. ثبّت **Android Studio** (نسخة Koala 2024.1 او احدث) و **Python 3.8+** على الكمبيوتر (يستعمله Chaquopy لتنزيل المكتبات وقت البناء).
2. افتح مجلد `ZahidBot` من Android Studio واترك الـ Gradle Sync يكمل (يحتاج انترنت).
3. من القائمة: **Build ▸ Build Bundle(s) / APK(s) ▸ Build APK(s)**.
4. الملف الناتج: `app/build/outputs/apk/debug/app-debug.apk` — انقله للهاتف وثبّته (فعّل "التثبيت من مصادر غير معروفة").

## اول تشغيل على الهاتف
التطبيق يشرح المطلوب ثم يطلب بالترتيب:
1. **الاشعارات** (لازمة لتبقى الخدمة شغالة في الخلفية).
2. **الغاء قيود البطارية** عن التطبيق (والا يقتله النظام).
3. **بيانات الحساب** تملأها في الشاشة: API ID، API HASH، Session String، Bot Token، يوزر البوت (بدون @)، ايدي المالك.
   - تُحفظ مشفّرة بـ Android Keystore على جهازك فقط.
   - التطبيق يتحقق من صحة شكل كل حقل قبل التشغيل.
4. اضغط **تشغيل**. السجل يظهر اسفل الشاشة.

خيار "تشغيل تلقائي بعد اقلاع الهاتف" موجود في نفس الشاشة.

## استخراج المتطلبات من داخل التطبيق
اذا لم تكن تملك البيانات، في اعلى الشاشة قسم "لا تملك المتطلبات؟":
1. **طريقة الحصول على API ID/HASH:** شرح بالخطوات وزر يفتح my.telegram.org (تيليجرام لا يسمح باستخراجها تلقائياً).
2. **استخراج الجلسة وايدي المالك:** تكتب رقمك ثم الكود (وكلمة سر التحقق بخطوتين ان وجدت)، فيُملأ حقل الجلسة وايدي المالك تلقائياً. رقم الهاتف والكود لا يُحفظان.
3. **انشاء بوت تلقائياً:** يراسل @BotFather من حسابك وينشئ البوت ويملأ التوكن واليوزر.
4. **جلب يوزر البوت من التوكن:** اذا عندك توكن جاهز.

> الجلسة تعطي صلاحية كاملة على حسابك، ولهذا تُحفظ مشفّرة. تيليجرام قد يرسل لك تنبيه "تسجيل دخول جديد" عند الاستخراج، وهذا طبيعي.

## كيف يعمل
- `BotService` (خدمة امامية + اشعار دائم) يشغّل بايثون عبر Chaquopy.
- `app/src/main/python/android_runner.py` ينسخ المصدر الى مخزن التطبيق، يكتب `config.py` من البيانات المدخلة، ويشغّل البوت.
- اوامر `.ايقاف` و `.اعاده تشغيل` تعمل (تم تحويل os._exit الى استدعاء للخدمة). اعاده التشغيل قد تأخذ بضع ثوان.
- بدل Redis يُستعمل `fakeredis`: **البيانات المخزنة (الردود، الاعدادات) تضيع عند ايقاف التطبيق.**

## قيود اندرويد (مهمة)
- **لا يوجد ffmpeg:** اوامر التحويل (متحركة، فيديو دائري، ملصق دائري، جلب لقطات...) تختفي تلقائياً من القائمة.
- **مكتبات غير مضمّنة** (لا يوجد لها بناء اندرويد جاهز): `moviepy`, `pymupdf`, `opencv`, `pymediainfo`, `pyminizip`, `PyGithub`, `tgcrypto`. اوامرها تختفي من القائمة تلقائياً. بدون `tgcrypto` يعمل البوت لكن اهدأ قليلاً.
- بعض الشركات (شاومي، هواوي، سامسونغ...) لها قيود بطارية اضافية: فعّل "التشغيل التلقائي" و"بدون قيود" للتطبيق من اعدادات الهاتف.
- اندرويد 15 يحدّد بعض انواع الخدمات الامامية؛ هذا المشروع يستعمل النوع `specialUse` لهذا السبب. لن يُقبل في Google Play، التثبيت اليدوي فقط.

## اذا فشل البناء
- **حزمة لا يوجد لها wheel:** افتح `app/build.gradle.kts` واحذف سطر `install("...")` المسبب. الاوامر المعتمدة عليها تختفي تلقائياً.
- **تعارض الاصدارات:** الاصدارات المستعملة (AGP 8.5.2، Kotlin 1.9.24، Chaquopy 16.0.0، Gradle 8.7، Python 3.11) لم أستطع تجربتها بنفسي؛ اذا اشتكى Android Studio اقبل اقتراحه بتحديث الاصدارات.
- **هاتف 32 بت:** اضف `"armeabi-v7a"` في `abiFilters`.

## امن
- لا تشارك ملف APK مع احد بعد وضع بياناتك (البيانات داخل مخزن التطبيق وليس في الـ APK، لكن الجلسة تعطي صلاحية كاملة على حسابك).
- اذا ظهر التوكن او الجلسة في اي مكان علني: اسحب التوكن من @BotFather وانهِ الجلسة من تيليجرام ▸ الاعدادات ▸ الاجهزة.

## بناء بدون Android Studio (عبر GitHub)
1. انشئ حساب في github.com ومستودع جديد (Repository) خاص.
2. ارفع محتويات مجلد `ZahidBot` كلها (Add file ▸ Upload files) — تأكد ان مجلد `.github` ضمن المرفوع.
3. افتح تبويب **Actions ▸ Build APK ▸ Run workflow**.
4. بعد 5–10 دقائق افتح التشغيل المنتهي ونزّل **ZahidBot-apk** (ملف zip فيه `app-debug.apk`).
